# RCIP 2.0.5

A documentation-only maintenance release. The npm README now explains explicit
operations, controlled data exposure, the framework-neutral core, and the measured
dispatch workflow. The site links the methodology and historical results.

Runtime behavior, public APIs, dependencies and protocol 1.0 are unchanged from
2.0.4. Benchmark timing receipts still identify the original pre-release candidate;
this documentation update does not create a new speed measurement.
