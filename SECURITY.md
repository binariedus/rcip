# Security

Please report suspected RCIP vulnerabilities privately through GitHub Security
Advisories for `binariedus/rcip`.

Do not include credentials, private application data, or exploit details in a
public issue. Include the affected RCIP version, impact, reproduction steps,
and any proposed mitigation in the private report.

Maintainers will acknowledge a valid report, investigate it, and coordinate a
fix and disclosure. Supported security fixes target the latest stable major
release.

For application integration requirements, see
[the RCIP security model](docs/security.md).
